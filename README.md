# Studio Catá Arquitetura

Website institucional do Studio Catá Arquitetura, desenvolvido com HTML, CSS e JavaScript (Vanilla), com deploy contínuo no Vercel.

## 🏗️ Sobre o Projeto

Website institucional do Studio Catá Arquitetura, desenvolvido para apresentar projetos e obras concluídas de forma clara e objetiva.

O projeto foi migrado de uma hospedagem tradicional (Hostgator / cPanel) para o Vercel, com foco em melhor performance, deploy contínuo e facilidade de manutenção.

A proposta do site é servir como um portfólio digital minimalista, priorizando a apresentação dos projetos arquitetônicos e refletindo a identidade visual e conceitual da arquiteta responsável, sem dependência de frameworks ou CMS.

Este projeto prioriza simplicidade, performance e facilidade de manutenção, servindo como base sólida para futuras evoluções.

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura do site
- **CSS3** - Estilização e responsividade
- **JavaScript (Vanilla)** - Interatividade e funcionalidades
- **Vercel** - Hospedagem e deploy

## 📁 Estrutura do Projeto

```
studiocata_vercel/
├── public_html/          # Arquivos principais do site
│   ├── css/             # Arquivos de estilo
│   ├── js/              # Arquivos JavaScript
│   ├── img/             # Imagens do site
│   ├── pags/            # Páginas individuais dos projetos
│   └── *.html           # Páginas principais
├── vercel.json          # Configuração do Vercel
├── package.json         # Dependências do projeto
└── README.md           # Este arquivo
```

## 🌐 Hospedagem

O domínio é gerenciado pela Hostgator, enquanto a aplicação está hospedada no Vercel.

## 📱 Páginas do Site

- **Home** (`index.html`) - Página principal com slider e projetos
- **Projetos** (`projetos.html`) - Lista de todos os projetos
- **Obras Concluídas** (`obras.html`) - Obras finalizadas
- **Sobre Nós** (`sobrenos.html`) - Informações sobre a empresa
- **Contato** (`contato.html`) - Informações de contato
